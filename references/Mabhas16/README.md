# مبحث شانزدهم مقررات ملی ساختمان — تأسیسات بهداشتی

## نسخه مورد نظر پروژه

- عنوان: مبحث شانزدهم مقررات ملی ساختمان ایران — تأسیسات بهداشتی
- ویرایش: چهارم
- سال ویرایش: ۱۳۹۶
- تهیه‌کننده: دفتر تدوین مقررات ملی ساختمان
- ناشر: مرکز تحقیقات راه، مسکن و شهرسازی

   https://mohammad-karimi.com/wp-content/uploads/2025/05/16.matn_.pdf

## هشدار نسخه

لینک سوم چاپ ۱۴۰۲ از ویرایش چهارم است؛ نباید آن را بدون بررسی تطبیق صفحه‌به‌صفحه، با چاپ/نسخه اولیه سال ۱۳۹۶ یکی دانست. برای استخراج مقررات پروژه، نسخه ۱۳۹۶ مبناست و هر نسخه چاپ مجدد باید جداگانه برچسب بخورد.

## محدوده استخراج داده

- فصل چهارم: لوله‌کشی فاضلاب بهداشتی ساختمان
- فصل پنجم: لوله‌کشی هواکش فاضلاب
- پیوست سوم: اندازه‌گذاری لوله‌ها در لوله‌کشی فاضلاب بهداشتی ساختمان
- پیوست پنجم: اندازه‌گذاری لوله‌ها در لوله‌کشی هواکش فاضلاب
- پیوست‌های علائم ترسیمی مرتبط
