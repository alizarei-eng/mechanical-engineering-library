## کنترل نسخه و اعتبار

- فایل PDF موجود در مخزن: چاپ ۱۴۰۲، ویرایش چهارم.
- در اطلاعات ثبت‌شده برای جدول‌ها، ویرایش ۱۳۹۶ نیز ذکر شده است. این دو مشخصه نباید با یکدیگر یکی فرض شوند.
- چهار جدول در فایل Markdown بازنویسی شده‌اند؛ بازبینی نهایی همه اعداد و عناوین ستون‌ها با PDF/نسخه فیزیکی هنوز لازم است.
- تا پیش از تأیید نهایی، مقدارهای JSON برای محاسبات قطعی مناسب نیستند.

## قواعد به‌روزرسانی

1. خروجی خام در source/ حفظ شود.
2. اصلاحات خوانا در فایل Markdown اعمال و دلیل اصلاح ثبت شود.
3. همان اصلاحات، بدون تغییر نوع یا مقدار داده، در tables.json منعکس شود.
4. پس از تطبیق با منبع، وضعیت جدول به‌صورت مستقل به‌روزرسانی شود.
