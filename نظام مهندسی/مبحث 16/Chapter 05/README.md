# Chapter 05 — فصل پنجم مبحث ۱۶

این پوشه محل نگهداری خروجی استخراج و جداول فصل پنجم است.

## فایل‌ها
- `جداول-فصل-۵.md`: نسخه خوانا از چهار جدول استخراج‌شده.
- `tables.json`: داده‌های ساختاریافته جدول‌ها (استخراج‌شده، هنوز تأیید نشده).
- `source/`: فایل‌های متن خام استخراج‌شده از PDF.


## وضعیت اعتبار
تمام داده‌ها خام و نیازمند تطبیق با نسخه PDF/کتاب اصلی هستند. مقادیر مشکوک یا بازسازی‌شده مشخص شده‌اند و نباید بدون بررسی به‌عنوان داده قطعی محاسباتی استفاده شوند.
