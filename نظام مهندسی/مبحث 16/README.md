## وضعیت تکمیل

| بخش | وضعیت |
|---|---|
| فصل پنجم | چهار جدول استخراج و بازنویسی شده؛ صحت‌سنجی نهایی در انتظار است |
| سایر فصل‌ها | هنوز محتوایی در این بخش ثبت نشده؛ پوشه خالی ایجاد نشده است |
| پیوست‌ها | فقط منابعی که محتوای واقعی دارند در مسیر منابع نگهداری می‌شوند؛ پوشه‌های خالی حذف شده‌اند |

## قواعد نگهداری

- خروجی خام در پوشه source/ نگهداری شود و دستکاری نشود.
- جدول خوانا در Markdown و داده قابل پردازش در JSON قرار گیرد.
- برای هر جدول، شماره جدول، صفحه PDF، واحدها، ترتیب ستون‌ها، ویرایش و وضعیت صحت‌سنجی ثبت شود.
- اصلاحات ساختاری یا عددی باید در مستندات توضیح داده شوند.
- تا زمان تأیید با نسخه مرجع، وضعیت داده extracted_unverified باقی بماند.
