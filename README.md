# کتابخانه مهندسی مکانیک و نظام مهندسی

مخزن مرجع برای نگهداری منابع مهندسی، استخراج متن و جدول‌ها، تبدیل داده‌های مقرراتی به قالب ساختاریافته و آماده‌سازی اطلاعات برای ابزارهای محاسباتی.

> **اصل مهم:** استخراج‌شدن یک مقدار به معنی تأییدشدن آن نیست. هیچ داده مقرراتی نباید پیش از تطبیق با نسخه مرجع و ثبت وضعیت صحت‌سنجی، وارد محاسبات نهایی شود.

## ساختار داده در هر مبحث

برای جلوگیری از مخلوط‌شدن داده خام با داده قابل استفاده در محاسبات، محتوای هر مبحث در سه گروه نگهداری می‌شود:

1. **source/**: خروجی خام استخراج‌شده از PDF؛ بدون اصلاح محتوای منبع.
2. **فایل‌های Markdown**: جدول‌ها و اطلاعات بازنویسی‌شده برای مطالعه و بازبینی انسانی.
3. **فایل‌های JSON**: داده‌های ساختاریافته برای استفاده آتی در نرم‌افزارها و محاسبات.

## وضعیت فعلی مبحث ۱۶

- منبع PDF چاپ ۱۴۰۲ در مسیر references/Mabhas16/ نگهداری می‌شود.
- برای فصل پنجم، چهار جدول در Markdown و JSON ثبت شده‌اند.
- داده‌های فصل پنجم هنوز نیازمند تطبیق نهایی با PDF/نسخه فیزیکی هستند.
- پوشه‌های فصل‌ها و پیوست‌ها ایجاد شده‌اند؛ وجود پوشه به معنی تکمیل استخراج آن بخش نیست.
- دو فایل نشریه ۱۲۸ جلد ششم در README مربوط به آن نمایه شده‌اند، اما فایل‌های PDF هنوز در مخزن بارگذاری نشده‌اند.

## قرارداد نام‌گذاری و ثبت داده

- برای هر جدول، شناسه یکتا، شماره صفحه PDF، شماره جدول، عنوان، ویرایش منبع و وضعیت صحت‌سنجی ثبت شود.
- مقادیر عددی، به‌ویژه قطرها و کسرهای مخلوط مانند 1 1/2، عیناً از مرجع کنترل شوند.
- اصلاحات کاربر یا اصلاحات حاصل از بازبینی باید از متن استخراج خام قابل تشخیص باشند.
- وضعیت‌ها به‌صورت روشن ثبت شوند: raw، extracted_unverified، verified یا rejected.
- فایل خام بازنویسی یا جایگزین نشود؛ اصلاحات در لایه داده و مستندات خوانا اعمال شوند.

## گردش کار پیشنهادی

1. تعیین نسخه و صفحه مرجع.
2. استخراج متن/جدول با ابزار موجود.
3. بازبینی چیدمان، ترتیب ستون‌ها، واحدها و اعداد.
4. ثبت نسخه خوانا در Markdown.
5. ثبت داده ساختاریافته در JSON.
6. تطبیق با PDF یا نسخه فیزیکی و به‌روزرسانی وضعیت صحت‌سنجی.
