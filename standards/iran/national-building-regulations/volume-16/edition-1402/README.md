# مبحث شانزدهم ـ تأسیسات بهداشتی
**مرجع:** مقررات ملی ساختمان ایران  
**ویرایش:** چهارم، چاپ ۱۴۰۲

## ساختار داده‌ها

- `source/`: فایل‌های خام و خروجی استخراج از PDF؛ هنوز صحت‌سنجی نشده‌اند.
- `tables/`: جدول‌های بازخوانی‌شده از خروجی استخراج، با حفظ مقادیر خام.
- `verified/`: داده‌هایی که با نسخه مرجع PDF یا نسخه فیزیکی تطبیق و تأیید شده‌اند.
